Mac installer for Loupe 0.3.4. If you have 0.3.x: choose **Check for Updates…** in the Loupe menu (Administrator Mode), then **Install and restart**. From an older version: see *Loupe - Install and quick start.pdf* below.

**New in 0.3.3 and 0.3.4**

- **Show Loupe in the Dock** switch at the bottom of the home window. Off means Loupe lives in the menu bar only; the magnifying glass menu has everything. On by default.
- **Discard** in the editor (⌘⌫): moves the capture to the Bin and closes the window, no questions asked. An image opened from outside the library is left alone; only the window closes.
- **Clearer Save feedback**: the Save button turns into *Saved ✓* for a moment, and an *Edited* badge sits next to the file name while there are unsaved changes.

**Fixed in 0.3.4**

- The Show Loupe in the Dock and Close capture after Copy switches were labelled "Timer" and could show the wrong state.
